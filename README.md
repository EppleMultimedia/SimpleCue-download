# SimpleCue – Download

**SimpleCue** ist ein schlankes Cue-System für Live-Playback von **Audio, Video und Bildern** auf Windows und macOS – bedient wie QLab (GO-Taste, Playhead, Folgemodi), bewusst reduziert, komplett auf Deutsch. Portable, keine Installation, offline, keine Telemetrie.

> Dieses Repository enthält **nur die fertigen Programmdateien** zum Download. Der Quellcode wird separat und privat gepflegt.

## Download

Die aktuelle Version findest du unter **[Releases](../../releases/latest)**:

| Plattform | Datei | Hinweis |
|---|---|---|
| **Windows** 10/11 (x64) | `SimpleCue-<version>-portable.exe` | Herunterladen und starten – keine Installation. |
| **macOS** (Apple Silicon) | `SimpleCue-<version>-arm64.dmg` | DMG öffnen, App in „Programme" ziehen. |

### Erster Start auf dem Mac
Die App ist nicht signiert. Beim ersten Öffnen einmal **Rechtsklick auf die App → „Öffnen"** und die Nachfrage bestätigen. Danach startet sie normal per Doppelklick.

### Windows
Beim ersten Start kann Windows SmartScreen eine Warnung zeigen („Weitere Informationen" → „Trotzdem ausführen"), da die Datei nicht signiert ist.

## Funktionen (Kurzüberblick)
- Cue-Liste als Show: Nummer, Name, Typ, Datei, Folgemodus, Notiz
- GO (Leertaste) / Playhead / „Alles stoppen"
- Folgemodi: Auf GO warten · Auto-Continue · Auto-Follow
- Audio mit dB-Lautstärke, Trim, Fades, Loop, Wellenform-Editor
- Video/Bild auf separatem Ausgabefenster (wählbarer Monitor/Beamer)
- Speichern/Laden (`.scue`) + „Show packen" (alle Medien mitkopieren)
